# Kamla Oil Industries

Website for **Kamla Oil Industries Private Limited** — biomass oil refinery in Hapur, Uttar Pradesh.

## Live site

- **https://www.kamlaoilindustries.com**
- **https://hmmittal19.github.io/Kamlaoils/**

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build for hosting (Hostinger / static upload)

```bash
npm run build
```

Upload the contents of the **`out`** folder to your web host (`public_html` on Hostinger).

## GitHub Pages deploy

Pushes to `Main` run `.github/workflows/deploy.yml`. In the repo go to **Settings → Pages** and set **Source** to **GitHub Actions** (not “Deploy from branch”).
